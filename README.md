# Project-1.1.6-Numbers-Riddle

## 📝 Project Description
This project is part of the **Project Lead The Way (PLTW) AP Computer Science A** curriculum under **Unit 1: Primitive Types**. The purpose of this program is to implement a interactive mathematical "number riddle" using Java. The application prompts a user for a secret number or takes an initial value, performs a series of mathematical transformations, and correctly predicts the final expected outcome based on algebraic properties.

### 🎯 Key Learning Objectives
* **Variables & Data Types:** Instantiating and managing primitive types (`int`, `double`).
* **Expressions & Assignment:** Utilizing standard arithmetic operators (`+`, `-`, `*`, `/`, `%`) and compound assignments (`+=`, `-=`, `*=`, `/=`).
* **Casting & Precision:** Handling intentional data conversions (widening and narrowing casting).
* **Debugging:** Identifying logic errors or intentional flaws within sequential operations.
