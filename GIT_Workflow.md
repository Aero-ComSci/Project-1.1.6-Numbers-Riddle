
# Git Workflow

Follow these steps to keep your local code synchronized with GitHub:

1. **Pull the latest changes**

   ```bash
   git pull
   ```

2. Write and save your code.

3. **Stage your changes**

   ```bash
   git add .
   ```

4. **Commit your changes**

   Replace the message with a short description of your work:

   ```bash
   git commit -m "Your commit message"
   ```

5. **Push your changes to GitHub**

   ```bash
   git push
   ```

> Pull before starting work and push when you finish.
